# PWA Implementation: Eenkaartjeleggen - Klaverjassen

**Goal:** Make the existing web application installable as a Progressive Web App (PWA).
**Approach:** PWA manifest + service worker meta tags + generated icon set
**App name:** Eenkaartjeleggen - Klaverjassen
**Status:** Implemented on branch `feature/mobile-app`

---

## What Was Implemented

Three minimal changes to the existing Flask application — no new dependencies, no separate project.

### 1. `static/sw.js` (new file — service worker)

Required by Android Chrome before it shows the install prompt. Caches static assets (CSS, JS, icons) for faster loads; passes WebSocket and game traffic directly to the network.

Served at `/sw.js` via a dedicated Flask route in `app.py` so its scope covers the whole app, not just `/static/`.

### 2. `static/manifest.webmanifest` (new file)

```json
{
  "name": "Eenkaartjeleggen - Klaverjassen",
  "short_name": "Klaverjassen",
  "description": "Multiplayer Klaverjassen kaartspel. Speel online met vrienden of tegen de computer.",
  "start_url": "/",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#2e7d32",
  "theme_color": "#2e7d32",
  "lang": "nl",
  "icons": [
    { "src": "/static/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/static/icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/static/icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

### 2. `templates/index.html` (6 lines added to `<head>`)

```html
<link rel="manifest" href="/static/manifest.webmanifest">
<meta name="theme-color" content="#2e7d32">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="Klaverjassen">
<link rel="apple-touch-icon" href="/static/icons/icon-180.png">
```

### 3. `static/icons/` (new folder — 4 icons)

Icons are generated by `mobile/generate_icons.py` using Pillow. Design: dark green felt background, white playing card, J ♣ (Jack of clubs).

| File | Size | Used for |
|------|------|---------|
| `icon-192.png` | 192×192 | Android Chrome install prompt |
| `icon-512.png` | 512×512 | PWA splash screen |
| `icon-maskable-512.png` | 512×512 | Android adaptive icon |
| `icon-180.png` | 180×180 | Apple touch icon (iOS Safari "Add to Home Screen") |

### 5. `static/icons/generate_icons.py` (icon generator)

Python script that regenerates all icons from scratch using Pillow. Run from the repo root whenever the icon design needs updating:

```bash
pip install Pillow
python static/icons/generate_icons.py
```

## How the PWA Install Works

**Android Chrome:**
1. User visits `https://eenkaartjeleggen.nl`
2. Chrome detects the manifest and shows an "Add to Home Screen" banner
3. App launches full-screen (no browser UI) with the green theme color

**iOS Safari:**
1. User visits `https://eenkaartjeleggen.nl`
2. Tap Share → "Add to Home Screen"
3. App uses the `icon-180.png` as the home screen icon and opens in standalone mode

**Desktop (Chrome / Edge):**
1. An install icon appears in the address bar
2. App opens as a standalone window

---

## Regenerating Icons

Icons are generated programmatically. To update the design, edit `static/icons/generate_icons.py` and re-run it:

```bash
python static/icons/generate_icons.py
```

The script tries to use the **Segoe UI Symbol** font (Windows) for the ♣ character, and falls back to drawing the clubs symbol from geometric primitives on other platforms.

---

## Deploying

No deployment changes are needed. The manifest and icons are served as static files by the existing Flask app. Once merged to `main`, the existing CI/CD pipeline deploys them automatically.

After deploy, verify the manifest is reachable:
```
https://eenkaartjeleggen.nl/static/manifest.webmanifest
```

## Future: Native App Store Distribution

If a Play Store or App Store listing is desired later, the PWA foundation is already in place. The recommended path would be a **Capacitor WebView wrapper** around the live URL:

| Store | Cost | Additional work |
|-------|------|----------------|
| Google Play | $25 one-time (account exists) | Capacitor project, signing keystore, Play Console listing |
| Apple App Store | $99/year | Apple Developer account, Capacitor + Xcode, App Store Connect listing |

The icons generated here (`icon-512.png`, `icon-maskable-512.png`) are already the correct sizes for Play Store submission.
